# Physical AI & World Model Study

Physical AI & World Model 스터디 문서를 웹사이트 형태로 정리한 공간입니다. 논문 흐름, 메타데이터, 15주/30회 커리큘럼, 논문별 curated note를 한 곳에서 탐색할 수 있도록 구성했습니다.

## 바로가기

| 섹션 | 설명 |
|---|---|
| [통합 문서](integrated.md) | Related Works, Paper Metadata, Curriculum을 합친 전체 문서 |
| [커리큘럼](curriculum.md) | 15주, 총 30회 발표 스터디 운영안 |
| [Related Works](related_works.md) | Physical AI와 World Model 연구 흐름 서술형 정리 |
| [Metadata](metadata.md) | 논문 제목, 저자, 소속, venue, link 정리 |
| [Paper Notes](papers/index.md) | 논문별 figure, 수식, notation, 핵심 요약 정리 |

## 추천 읽기 흐름

1. [Related Works](related_works.md)에서 전체 연구 지형을 먼저 봅니다.
2. [통합 문서](integrated.md)의 `전체 논문 읽기 순서와 Curated Note 링크`를 따라 논문별 note로 이동합니다.
3. 각 논문 note의 `읽기 전 약어 및 핵심 용어`를 먼저 확인한 뒤 본문을 읽습니다.
4. 발표 준비자는 [커리큘럼](curriculum.md)의 회차별 발표 목표와 질문을 함께 확인합니다.

```bash
python3 -m mkdocs serve
```
