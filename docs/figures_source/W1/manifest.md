# W1 Source Figures

Source article: https://www.nature.com/articles/nrn2787

Nature Reviews Neuroscience does not provide an arXiv TeX source for this article, so these figures were saved from the official Nature article image assets.

| Local file | Source figure | Caption summary |
|---|---|---|
| `W1_fig1_birdsong.jpg` | Figure 1 | Birdsongs and perceptual categorization. The simulation uses a generative model of birdsong and shows perceptual inference as free-energy minimization over internal representations of causal states. |
| `W1_fig2_reaching.jpg` | Figure 2 | A demonstration of cued reaching movements. The figure shows active inference for motor control, where proprioceptive and visual prediction errors drive hidden-state inference and action. |
| `W1_fig3_mountain_car.jpg` | Figure 3 | Solving the mountain car problem with prior expectations. The example shows adaptive exploratory behavior emerging from priors on hidden-state motion and active inference. |
