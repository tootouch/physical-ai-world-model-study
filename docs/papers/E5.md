# E5. Why learn if you can infer? Robot arm control with Hierarchical Active Inference

## 2. 핵심 요약

이 논문은 robot arm control을 black-box RL로 학습하는 대신, robot arm의 kinematic chain structure를 반영한 generative model 위에서 inference 문제로 다룬다. 저자들은 active inference가 RL의 매력적인 일반성은 유지하면서도, expensive training 없이 forward kinematics 기반 방법의 효율성을 얻을 수 있다고 주장한다.

## 3. 핵심 수식

Active inference는 관측과 latent state의 generative model을 두고 variational free energy를 줄이는 방식으로 볼 수 있다.

$$
F(q)
=
\mathbb{E}_{q(s)}
\left[
\log q(s)
-
\log p(o, s)
\right]
$$

| 기호 | 의미 |
|---|---|
| $F(q)$ | variational free energy |
| $q(s)$ | latent state에 대한 approximate posterior |
| $p(o, s)$ | observation과 latent state의 generative model |
| $o$ | 관측, 예를 들어 end-effector 위치나 sensory state |
| $s$ | latent state, 예를 들어 joint configuration |

robot control 관점에서는 원하는 관측을 만들기 위해 action을 직접 학습하기보다, generative model 아래에서 어떤 latent state/action이 관측을 설명하거나 달성하는지 추론한다.

## 4. 스터디 연결

이 논문은 W1 Free Energy Principle과 직접 연결된다. 또한 W2 DreamerV3나 W12 DreamZero처럼 학습 기반 world model을 쓰는 흐름과 대비된다. 여기서는 "학습한 policy"보다 "구조가 주어진 generative model에서의 inference"가 중심이다.

Physical AI 연구에서 이 관점은 data-efficient control, safety-critical manipulation, kinematic prior를 가진 robot arm control에 유용한 대안적 사고방식이다.
