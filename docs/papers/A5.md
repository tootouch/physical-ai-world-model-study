# A5. BotSim: LLM-Powered Malicious Social Botnet Simulation

## 0. 읽기 전 약어 및 핵심 용어

이 문서를 읽기 전에 아래 약어와 용어를 먼저 정리한다. 이후 본문에서는 괄호 안의 약어를 사용한다.

- Artificial Intelligence (AI): 사람의 지각, 추론, 학습, 의사결정 능력을 기계가 수행하도록 만드는 인공지능 분야를 뜻한다.
- Large Language Model (LLM): 대규모 텍스트 데이터로 학습되어 언어 이해, 생성, 추론, 계획에 쓰이는 foundation model이다.

- Physical Artificial Intelligence (Physical AI): 디지털 공간의 예측을 넘어 물리 세계에서 지각, 예측, 계획, 행동, 안전 검사를 수행하는 AI 시스템을 뜻한다.

## 2. 핵심 요약

BotSim은 LLM 기반 malicious social botnet을 시뮬레이션하는 framework다. 가상 소셜 네트워크 안에서 agent bots와 real human users가 상호작용하고, bot들이 posting/commenting을 수행하며 misinformation dissemination을 만든다. BotSim-24 dataset으로 기존 bot detection 전략이 LLM-powered bot에 취약하다는 점을 보인다.

## 3. Physical AI와의 연결

직접적인 robot paper는 아니지만, autonomous agents가 사회적 환경에서 어떤 위험을 만들 수 있는지 보여준다. Physical AI가 공장, 물류, 병원, 가정으로 들어가면 malicious instruction, coordinated agent misuse, synthetic behavior detection 같은 문제가 생길 수 있다. BotSim은 agent simulation을 safety evaluation에 쓰는 예시로 볼 수 있다.

## 4. 발표 포인트

이 논문은 core curriculum에는 넣기보다 "agent simulation and safety" 보조 자료로 두는 것이 적절하다. Physical AI에서도 공격적/비정상적 agent behavior를 사전에 simulation하는 framework가 필요할 수 있다.
