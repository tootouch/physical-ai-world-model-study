# A4. Synergistic Multi-Agent Framework with Trajectory Learning for Knowledge-Intensive Tasks

## 0. 읽기 전 약어 및 핵심 용어

이 문서를 읽기 전에 아래 약어와 용어를 먼저 정리한다. 이후 본문에서는 괄호 안의 약어를 사용한다.

- Artificial Intelligence (AI): 사람의 지각, 추론, 학습, 의사결정 능력을 기계가 수행하도록 만드는 인공지능 분야를 뜻한다.
- Computer-Aided Design (CAD): 물체의 3D geometry나 설계 정보를 컴퓨터로 표현한 model이다.
- Standard Operating Procedure (SOP): 조직이나 agent가 task를 수행할 때 따르는 표준 절차나 protocol이다.
- Physical Artificial Intelligence (Physical AI): 디지털 공간의 예측을 넘어 물리 세계에서 지각, 예측, 계획, 행동, 안전 검사를 수행하는 AI 시스템을 뜻한다.

## 2. 핵심 요약

SMART는 knowledge-intensive task에서 hallucination, long-tailed knowledge, limited memory expansion 문제를 완화하기 위해 외부 지식을 활용하는 multi-agent framework다. 네 개의 specialized agents가 sub-trajectory action을 수행하며, Long-Short Trajectory Learning으로 agent 간 협력과 fine-grained execution을 동시에 학습한다.

## 3. Physical AI와의 연결

로봇이 현장에서 작업할 때도 domain manual, CAD, SOP, maintenance history, safety rule 같은 외부 지식이 중요하다. SMART의 trajectory learning 관점은 embodied agent가 지식 검색과 행동 계획을 분리된 module이 아니라 협력하는 agent trajectory로 다룰 수 있음을 보여준다.

## 4. 발표 포인트

이 논문은 직접적인 로봇 제어보다는 knowledge-grounded multi-agent reasoning에 가깝다. 하지만 Physical AI 시스템에 external knowledge와 long-horizon plan verification을 넣을 때 참고할 수 있다.
