## 2. 핵심 요약

ProAgent는 zero-shot coordination 상황에서 LLM을 활용해 teammate의 의도를 추론하고, 실제 행동을 관찰하며 belief를 업데이트하는 proactive cooperative agent framework다. Overcooked-AI에서 self-play나 population-based training 기반 방법보다 낯선 AI agent 및 human proxy와의 협력 성능이 높다고 보고한다.

## 3. Physical AI와의 연결

Physical AI가 단일 로봇 제어를 넘어 multi-robot, human-robot collaboration으로 가면 teammate modeling이 필수다. ProAgent의 핵심은 "상대가 무엇을 하려는지"를 추론하고 자신의 행동을 조정하는 것이다. 이는 S3의 mental world model, E2의 monitoring/re-planning, 그리고 현장 로봇 fleet coordination과 연결된다.

## 4. 발표 포인트

이 논문은 로봇 제어 논문이라기보다 cooperative agent architecture 논문이다. 따라서 curriculum 본류에서는 보조 자료로 두고, human-robot collaboration 또는 multi-agent planning을 소개할 때 짧게 연결하는 것이 적합하다.
