# A2. REVECA: Adaptive Planning and Trajectory-Based Validation in Cooperative Language Agents

## 0. 읽기 전 약어 및 핵심 용어

이 문서를 읽기 전에 아래 약어와 용어를 먼저 정리한다. 이후 본문에서는 괄호 안의 약어를 사용한다.

- Artificial Intelligence (AI): 사람의 지각, 추론, 학습, 의사결정 능력을 기계가 수행하도록 만드는 인공지능 분야를 뜻한다.
- Vision-Language-Action (VLA): 시각 관측과 언어 명령을 함께 받아 로봇 action까지 생성하는 모델 또는 학습 패러다임이다.
- World Action Model (WAM): video/world model이 action과 future observation을 함께 모델링해 policy처럼 쓰일 수 있게 만든 모델이다.
- RElevance, Proximity, and Validation-Enhanced Cooperative Language Agent (REVECA): information relevance, relative proximity, trajectory validation을 이용하는 cooperative language agent architecture이다.
- Physical Artificial Intelligence (Physical AI): 디지털 공간의 예측을 넘어 물리 세계에서 지각, 예측, 계획, 행동, 안전 검사를 수행하는 AI 시스템을 뜻한다.

## 2. 핵심 요약

REVECA는 decentralized agents가 partial observation 아래에서 협력할 때 발생하는 memory overload, collaborator를 고려하지 않은 globally suboptimal planning, 환경 변화로 인한 false planning 문제를 다룬다. Relevance Estimation, Adaptive Planning, Trajectory-based Validation을 통해 memory management, planning, false planning prevention을 결합한다.

## 3. Physical AI와의 연결

로봇 여러 대가 같은 작업 공간에서 협력하면 각 agent는 전체 상태를 완전히 볼 수 없고, 다른 agent의 행동 때문에 계획이 틀어질 수 있다. REVECA의 trajectory-based validation은 physical multi-agent planning에서도 중요한 사고방식이다. 계획이 맞는지 실행 궤적 관점에서 계속 검증해야 한다는 점이 E2 Code-as-Monitor와도 연결된다.

## 4. 발표 포인트

이 논문은 VLA/WAM 직접 논문은 아니지만, 협력형 Physical AI의 planning validation 구조를 생각하게 해준다. 운영/현장 적용 관점에서는 multi-agent workflow, memory prioritization, trajectory validation을 현장 운영 최적화 문제와 연결할 수 있다.
