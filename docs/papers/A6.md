## 2. 핵심 요약

DoG는 knowledge graph question answering에서 긴 reasoning path와 false-positive relation 문제를 줄이기 위한 iterative interactive framework다. subgraph-focusing mechanism으로 각 reasoning step 이후 answer trying을 수행하고, multi-role debate team이 복잡한 질문을 점진적으로 단순화한다. WebQuestions와 GrailQA에서 ToG보다 높은 accuracy를 보인다고 보고한다.

## 3. Physical AI와의 연결

Physical AI가 현장 지식 그래프를 활용한다면, object, tool, process, safety rule, spatial relation이 graph로 표현될 수 있다. DoG는 graph reasoning을 debate와 validation으로 안정화하는 방법을 제시한다. 이는 로봇 task planning에서 wrong relation이나 irrelevant path 때문에 잘못된 계획이 나오는 문제와 연결된다.

## 4. 발표 포인트

이 논문은 embodied control보다는 symbolic/graph reasoning에 가깝다. 하지만 VLA가 black-box로만 움직이지 않고 external graph memory를 참조하는 방향으로 갈 때 연결 가치가 있다.
